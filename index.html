About the Workshop

Leaderboards evaluate language model agents against a frozen snapshot of their environment. Deployed agents work in a moving one: the IT estate, the databases, documents, and policies the agent reads but does not own, edited on other teams' schedules. That movement deposits stale state the agent reasons over—the estate-facing manifestation of Agentic Technical Debt (ATD)—and levies a Stochastic Tax (ST), the recurring cost of keeping behavior bounded through self-repair loops and verification routines.

This workshop bridges machine learning evaluation with software engineering and system dynamics to address the end-to-end reliability of long-horizon autonomous systems.

Core Focus Tracks

1. Coupled Benchmarks

Methods for evaluating agents against dynamic environments using ground-truth-invariant perturbations.

2. Agentic Debt (ATD)

Quantifying internal system context decay, stale state tracking, and memory contamination profiles.

3. Stochastic Tax (ST)

Measuring the operational compute footprint, error propagation, and failure rates over massive execution paths.
